# Habit Tracker Watch — Samsung Galaxy Watch 4 Classic

Нативный автономный Wear OS проект на Kotlin + Jetpack Compose for Wear OS.

## Реализовано
- Wear OS-приложение с круглым компактным интерфейсом и тёмной AMOLED-палитрой.
- Главная страница и разделы «Привычки», «Школа», «Задания», «Статистика».
- Добавление привычек, отметка выполнения и удаление последней привычки.
- Домашние задания: добавление, отметка выполнения, удаление последнего задания.
- Расписание с понедельника по пятницу и заданным временем уроков.
- Локальное сохранение списка привычек, отметок на текущую дату и домашних заданий через SharedPreferences.
- Обработка вращения безеля через Compose rotary scroll input.
- Иконка приложения и standalone Wear OS metadata.
- Не запрашивает разрешения на сеть, местоположение, датчики или уведомления: эти возможности в текущей версии не используются.

## Ограничения этой версии
- Расписание зашито в приложение и пока не редактируется на часах.
- В понедельник первый указанный предмет — урок №2, поскольку урок №1 в исходном расписании не был указан.
- Статистика показывает данные текущего дня, а не исторические графики.
- Данные хранятся локально на часах; сопряжение и синхронизация со смартфоном не требуются.
- Код рассчитан на Wear OS/API 30+ и Galaxy Watch 4 Classic. Физическая проверка на часах не выполнялась.

## Сборка APK
Требования: Android Studio с Android SDK 35, JDK 17 или новее, доступ к Google Maven и Maven Central при первой синхронизации Gradle.

1. Распакуйте ZIP.
2. В Android Studio выберите **Open** и укажите папку `HabitTrackerWatch`.
3. Дождитесь Gradle Sync и установки необходимых SDK-компонентов.
4. Выполните **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. APK будет создан по адресу `app/build/outputs/apk/debug/app-debug.apk`.
6. Для переименования итогового файла используйте имя `GalaxyWatchApp.apk`.

## Установка на Galaxy Watch 4 Classic
1. На часах откройте **Настройки → О часах → Сведения о ПО** и несколько раз нажмите «Версия ПО», чтобы включить параметры разработчика.
2. В параметрах разработчика включите **ADB debugging** и **Wireless debugging** (названия могут немного различаться по версии Wear OS).
3. Подключите часы и компьютер к одной Wi‑Fi сети. На часах откройте экран Wireless debugging и используйте показанный адрес/порт и код сопряжения.
4. В Android SDK Platform Tools выполните `adb pair IP:PAIR_PORT`, введите код сопряжения, затем `adb connect IP:CONNECT_PORT`.
5. Установите APK командой `adb install -r GalaxyWatchApp.apk`.
6. После установки отключите ADB/Wireless debugging, если они больше не нужны.

Команды ADB и порты нужно брать с экрана самих часов; не используйте чужие адреса или коды.
